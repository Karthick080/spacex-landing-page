# 🚀 SpaceX Landing Page

This is a simple SpaceX-inspired landing page that I created using HTML and CSS.

I made this project to practice my frontend development skills and to understand how to build a clean website layout from scratch.

## 🖥️ About the Project

The website has a dark and simple space-themed design.

It includes:

- Navigation bar
- Hero section
- Mission section
- Vehicles section
- About section
- Call-to-action section
- Footer
- Mobile responsive design

## 🛠️ Technologies Used

- HTML
- CSS
